Como esta loja está implantada

  • Camada pública — serviço web (Nginx). É o único com ports: "8080:80". Equivale a uma sub-rede pública com regra de grupo de segurança liberando a porta 80.
  • Camada privada — API — serviço api (traefik/whoami), sem ports:. Só é alcançada pelo proxy reverso do Nginx na rota /api/.
  • Camada privada — Banco — serviço banco (Redis), sem ports:. Responde apenas de dentro da rede interna do Docker.
